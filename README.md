# News Image — 17 November 2026

This repository contains a single-image front-page summary of the world's news on Tuesday 17 November 2026 for the make.fun news-image-20261117 competition.

## Stories Covered
- Kerch Bridge hit again / Kyiv bridges struck
- Tankers mined near Hormuz and Iran's drones at a US radar base in Bahrain intercepted with no casualties
- Xi–Trump–Putin three-way meeting confirmed for 19 Nov in Shenzhen
- Pentagon fails audit for a 9th year
- Japan scrambles jets after suspected Russian airspace violation
- UK sanctions Israeli settlement builders and allies urge Gaza crossings opened

## Usage
- Run `python3 draw.py` to render `entry.png`.
- Run `node main.ts` to copy `entry.png` to the output directory (`MAKEFUN_OUTPUT_DIR` or `/output`).
